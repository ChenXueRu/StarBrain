# StarBrain 收件匣（Google Apps Script）

電腦連不到時（當機、斷電、重開機中），手機上新增的紀錄與想法會改送到這個收件匣，存成你 Google Drive 裡 `StarBrain_Inbox` 資料夾的 `.json` 檔。電腦上的 StarBrain 開機後會自動領取、匯入，再把檔案丟進垃圾桶。

## 部署（只需要做一次）

1. 打開 <https://script.google.com>，按「新專案」，專案名稱取 `StarBrain 收件匣`。
2. 把編輯器裡的內容全部刪掉，貼上同資料夾的 `Code.gs`，按儲存。
3. 上方函式選單選 `setup`，按「執行」。第一次會要求授權（存取你的 Google Drive），照畫面同意。
4. 打開下方的「執行紀錄」，會看到兩行：
   - `PUT_TOKEN`：手機用的鑰匙
   - `ADMIN_TOKEN`：電腦用的鑰匙
5. 右上角「部署」→「新增部署作業」→ 類型選「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**（靠鑰匙保護，沒有鑰匙什麼都拿不到）
6. 按「部署」，複製「網頁應用程式網址」（結尾是 `/exec`）。
7. 打開 StarBrain →「設定」→「手機收件匣」，依序填入：
   - 網頁應用程式網址：步驟 6 複製的網址
   - PUT_TOKEN：步驟 4 的手機用鑰匙
   - ADMIN_TOKEN：步驟 4 的電腦用鑰匙（密碼欄位，只寫入不顯示，欄位標題會顯示「已設定／未設定」；要移除時勾選「清除已儲存的 ADMIN_TOKEN」再儲存）

   按「儲存」。可以按「立即同步」測試，下方會顯示上次同步的時間、匯入筆數或錯誤；之後電腦上的 StarBrain 開機時與每 5 分鐘都會自動領取。網址與 `PUT_TOKEN` 會記在手機上（電腦關機時才送得出去），`ADMIN_TOKEN` 只存在電腦的 `secrets.json`，不會傳到手機。要讓手機記下設定，儲存後請在手機上開啟一次 StarBrain 並連上電腦。

## 之後改了 Code.gs

「部署」→「管理部署作業」→ 編輯（鉛筆）→ 版本選「新版本」→ 部署。網址不會變。

## 安全

- 鑰匙不要貼到別的地方。外洩時，到專案設定的「指令碼屬性」刪掉 `PUT_TOKEN` 或 `ADMIN_TOKEN`，再執行一次 `setup()` 產生新的，然後回 StarBrain 設定更新。
- 這個網址只收「新增紀錄 / 新增想法」，不能讀取或修改你宇宙裡的任何資料。
