# StarBrain 執行計畫

> 把每天的經驗記成星星，看見自己何時用「快思考」、何時用「慢思考」，以及哪裡需要加強。

---

## 一、核心概念

### 1. 思考架構（一顆星體的內部）

每顆星體的中心是一個 **主題（恆星）**，一筆紀錄依序走過七個節點：

```
Input → 問題 → 意識 → 想法 → 思維 → 思考 → 觀點 → 結論 → Output
```

| 節點 | 填什麼 | 例子 |
|---|---|---|
| 問題 | 發生了什麼 | 報告被主管退回 |
| 意識 | 我察覺到什麼 | 我有點不服氣 |
| 想法 | 第一個冒出的念頭（直覺） | 他沒看懂 |
| 思維 | 我用什麼角度去看 | 換成主管的立場 |
| 思考 | 實際推敲、比較選項 | 重點放錯位置了 |
| 觀點 | 我的判斷 | 報告要先寫結論 |
| 結論 | 最後做了什麼／產出 | 改版後通過 |

- 只有「問題」必填，其他選填。
- **慢思考** = 有走過「思維、思考」。
- **快思考** = 從想法直接跳到結論。

### 2. 星體規則

| 狀況 | 結果 | 圖上的樣子 |
|---|---|---|
| 第一次遇到 | 誕生 **初星體** | 小圓 |
| 有成功的產出 | **點亮** | 發光的星 |
| 沒有產出 | 維持 **黯淡** | 灰色小圓 |
| 再次遇到，有走慢思考 | 升級為二等星、三等星…最高六等 | 越來越大的漩渦 |
| 再次遇到，跳過思考 | 不升級，記一次 **快思考** | — |

升級門檻與最高等級可在齒輪設定中調整。

判定細節：
- 紀錄依發生時間排序，最早的一筆是「誕生」，初次遇到不算快思考。
- 之後的紀錄有填「思維」或「思考」就是慢思考，兩格都空就是快思考。
- 等級 = 1 + 慢思考次數 ÷ 每升一等需要的次數（取整數），不超過最高等級。
- 任何一筆結果是「成功」，星體就點亮。
- 等級與亮暗都是即時從紀錄推算，補改紀錄後會自動重算。

### 3. 宇宙層級

```
星體 → 星系 → 星系群 → 星系團 → 超星系團 → 可觀測宇宙
```

| 層級 | 代表意義 | 範例 |
|---|---|---|
| 星體 | 一件具體的事 | 跟主管回報進度 |
| 星系 | 目標一致的星體 = 一項技能 | 職場溝通 |
| 星系群 | 多項技能結合 = 專屬技能 | 專案管理 |
| 星系團 | 一個領域 | 工作專業 |
| 超星系團 | 三大面向之一 | 職業能力／生活態度／價值觀 |
| 可觀測宇宙 | 完整的你 | — |

- 層級不寫死：層數與名稱可在設定中調整，資料少時只顯示用得到的層級，之後依實際案例再調整。
- 星體 → 星系：AI 依「目標」建議歸類，你確認後相連。
- 星系雲、情境分類都可以新增、修改、刪除。

### 4. 最終要回答的兩個問題

1. **我何時用快思考、何時用慢思考？**
2. **我哪裡需要加強？**
   - 快思考 + 成功 → 已內化的技能
   - 快思考 + 失敗 → 該停下來想的地方（優先加強）
   - 長期黯淡的星系 → 尚未掌握的技能

## 二、系統架構

```
 手機 / 電腦瀏覽器（PWA）
          │
          ▼
 starbrain.example.com ── Cloudflare Tunnel + Access（只有你能登入）
          │
          ▼
 家裡常駐電腦
 ├─ 後端服務 ── SQLite 資料庫（快速、輕量）
 ├─ 本地 AI（Ollama）
 └─ 主流 AI API（Claude / OpenAI / Gemini）
          │
          ▼
 Google Drive ── 每日自動備份
```

### Google Drive 可行性評估

| 做法 | 可行 | 結論 |
|---|---|---|
| Google Drive 當主資料庫 | 可以，但每次讀寫都要連網，速度慢，兩台裝置同時改會衝突 | ❌ 不建議 |
| 資料庫放在 Drive 同步資料夾 | SQLite 開啟中被同步，容易損毀 | ❌ 不建議 |
| **電腦本地 SQLite + Drive 自動備份** | 讀寫快；Drive 保存每日備份，可一鍵還原 | ✅ 採用 |

**手機電腦同步** 由 Cloudflare 子網域達成：兩邊連的都是同一台電腦上的同一份資料，不需要另外同步。

**電腦關機時**：手機的紀錄先暫存在手機上，電腦開機後自動補送。

### 技術選型

| 項目 | 選擇 |
|---|---|
| 前端 | Vite + React + TypeScript，PWA |
| 3D | Three.js（react-three-fiber） |
| 後端 | Node.js + TypeScript（前後端同一種語言） |
| 資料庫 | SQLite |
| 連線 | Cloudflare Tunnel + Cloudflare Access |
| AI | 設定中可切換：本地 Ollama／本機 OpenAI 相容／Claude／OpenAI／Gemini |
| 語音輸入 | 瀏覽器內建語音辨識（之後可換本地 Whisper） |

### 發佈到 GitHub（空白專案）

- 專案裡不含任何個人資料：資料庫、金鑰、備份都在專案以外的資料夾。
- 提供 `.env.example` 與安裝說明（Cloudflare、Google Drive、Ollama 設定步驟）。
- 別人下載後是一個全新、空白的宇宙。

## 三、執行清單

每個階段完成後都能實際使用，通過「驗收」再往下走。

### 階段 1　專案骨架
- [x] 建立前端、後端兩個資料夾，git 初始化
- [x] `.gitignore` 排除資料與金鑰，`.env.example`、README、授權條款
- [x] 手機／電腦兩種版面框架

**驗收：** 電腦上開得起來；`git status` 看不到任何資料或金鑰檔。

### 階段 2　後端與資料
- [x] SQLite 資料表：紀錄、星體、層級群組、情境分類、設定
- [x] 後端 API：新增、查詢、修改、刪除
- [x] 匯出／匯入 JSON

**驗收：** 新增資料後重啟服務仍在；匯出再匯入結果相同。

### 階段 3　快速紀錄（手動）
- [x] 一行輸入：問題 + 情境分類 + 結果（成功／未成功／還不知道）
- [x] 展開可補填七個節點
- [x] 自動提示「這是不是以前遇過的事？」→ 確認後歸到同一顆星
- [x] 情境分類的新增、修改、刪除

**驗收：** 一筆紀錄 30 秒內完成；重複事件能正確合併。

### 階段 4　星體規則
- [x] 初星體誕生、點亮／黯淡
- [x] 慢思考 → 升等；快思考 → 只記錄不升級
- [x] 星體歸入星系、星系以上的歸類

**驗收：** 用測試資料跑過，每種情況都符合「星體規則」表。

### 階段 5　3D 宇宙
- [x] 星體依等級顯示大小、依亮暗顯示光度
- [x] 慢速自轉、繞星系中心公轉
- [x] 層級縮放：拉遠看星系團，拉近看單顆星
- [x] 點擊星體 → 顯示它的紀錄與七個節點
- [x] 手機效能調整

**驗收：** 手機上旋轉縮放流暢，動畫慢而穩定。

### 階段 6　連線與備份
- [ ] Cloudflare Tunnel 接上子網域，Cloudflare Access 限定只有你能登入（由使用者在 Cloudflare 設定，步驟見 [DEPLOY.md](DEPLOY.md)）
- [x] PWA 安裝到手機桌面；電腦關機時先暫存、開機後補送
- [x] 每日自動備份到資料夾、一鍵還原、匯出／匯入 JSON
- [ ] 備份資料夾指到 Google Drive 電腦版，同步到雲端（需先安裝 Google Drive 電腦版）

**驗收：** 手機用 4G 能記錄；電腦關機時記的資料，開機後有出現；從 Drive 還原成功。

### 階段 7　AI 對話框
- [x] 宇宙下方對話框
- [x] 設定中切換模型：本地 Ollama／本機 OpenAI 相容（vLLM、LM Studio）／Claude／OpenAI／Gemini
- [x] 打字或語音說一整串 → AI 拆成七個節點、建議分類與星系 → 你確認後存入
- [x] 可以問宇宙：「我這週在哪裡用了快思考？」

**驗收：** 口語描述一件事，AI 整理的結果 8 成以上不需修改。

回歸測試：`EVAL_AI_MODEL=<模型> EVAL_AI_URL=<網址> npm run eval:parse -w apps/server`，固定 8 句口語，檢查快慢思考、結果、分類、不編造、有拆開。本機 Qwen3.6 27B（關閉思考）調整提示詞後 24/24 通過（每句 3 次），另外 6 句驗證句的快慢判定也都正確。

### 階段 8　回顧分析與發佈
- [x] 快／慢思考比例（依情境、依時間）
- [x] 「快思考 + 失敗」清單、長期黯淡星系提醒
- [x] 每週回顧摘要（本週與上週比較；有啟用 AI 時可請 AI 寫一段回顧）
- [x] 進階設定全部收進齒輪
- [x] 發佈空白專案到 GitHub（https://github.com/ChenXueRu/StarBrain）

**驗收：** 主畫面只有「宇宙 + 對話框」；別人照 README 能裝出一個空白宇宙。

### 追加　想法收件匣（由 Aru Hub 的「想法與靈感」搬入）
- [x] 收件匣：一行記一筆、由新到舊、修改、刪除、完成／取消完成、已完成區可收起
- [x] PWA 基礎：manifest、圖示、service worker、「記下想法」捷徑（階段 6 的離線暫存另做）
- [x] 匯入 Hub 直接相關的 5 筆想法，保留原建立時間
- [x] 想法整理後轉成星體

> 想法先放收件匣、整理後再變成星體，避免產生一堆黯淡的初星體。

## 五、已確認的決策

| 項目 | 決定 |
|---|---|
| 思考架構 | 依手繪圖：問題 → 意識 → 想法 → 思維 → 思考 → 觀點 → 結論 |
| 資料 | 電腦本地為主，Google Drive 備份 |

| 使用者 | 只有你；空白專案發佈到 GitHub |
